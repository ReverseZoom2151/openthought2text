# Paper-fidelity status

The project is informed by Thought2Text, GLIM, GraphAlign, Brain2Qwerty,
NeuSpeech, CET-MAE/E2T-PTR, DeWave, LaBraM, BrainMagick, MEG-XL, ActiveLBLM,
and semantic-decoding research.

No result is currently claimed as a reproduction. Future reproduction reports
will state the exact paper version, data access, preprocessing, architecture,
split, generation protocol, controls, deviations, compute, and licensing.

NeuSpeech-style target-free generation and label-invariance checks are required
for all sequence-to-sequence comparisons. A teacher-forced token-logit result is
a diagnostic, not a text-generation reproduction.
